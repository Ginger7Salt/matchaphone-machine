# 茶茶机

> 本项目为公开源码项目，允许非商业二次开发和小范围分享。
> 不允许商业使用、商业托管、商业分发或出售。

茶茶机是一个面向移动设备的 AI 角色聊天与线下见面应用。项目源码公开，欢迎大家学习、改进和在自己的设备或环境中部署。

## 在线使用

官方在线地址：

<https://matchaphone-d5gjgy87ybfb50382-1463048417.tcloudbaseapp.com/>

> 在线使用茶茶机时，需要用户自行配置可用的 Provider Base URL、API Key 和模型。项目作者不提供模型 API Key，也不建议把任何密钥提交到代码仓库、截图、日志或公开 Issue 中。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

请根据当前项目的包管理器锁文件选择对应的 Node.js 版本和包管理器。API 设置通常只需要填写 Base URL、API Key 和模型名称并保存；测试连接、拉取模型以及高级兼容性诊断属于可选功能。
